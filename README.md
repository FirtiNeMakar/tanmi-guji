# 探秘古迹 — 考古研学小程序原型

移动端优先的 React + TypeScript + Vite 网页原型。界面主要使用中文，项目说明见下方俄语说明。

## Запуск в VS Code (Windows PowerShell)

1. Распакуй ZIP.
2. Открой папку `tanmi-guji` в VS Code.
3. Открой `Terminal → New Terminal`.
4. Установи зависимости:

   ```powershell
   npm.cmd install
   ```

5. Запусти проект:

   ```powershell
   npm.cmd run dev
   ```

6. Открой адрес, который покажет Vite (обычно `http://localhost:5173`).

Если в PowerShell `npm` блокируется политикой сценариев, используй `npm.cmd`.

## Что работает в прототипе

- Главная страница и мобильная нижняя навигация.
- «云探方» — интерактивная раскопка: проводи мышью или пальцем по слою земли, чтобы открыть находку.
- Карточка учебного артефакта и сохранение найденного предмета.
- «文物修复师» — простая игра по сборке керамического сосуда нажатием на фрагменты.
- «研学护照» — коллекция печатей и прогресс.
- «博古通今» — ежедневная викторина с проверкой ответа.
- Прогресс и найденные артефакты сохраняются в LocalStorage браузера.

## Ограничения демонстрационной версии

- Данные, артефакты и слои учебные и демонстрационные; это не археологическая атрибуция.
- GPS, серверные аккаунты, облачная синхронизация, реальное AI-распознавание и полноценные 3D-модели не подключены.
- Вибрация зависит от поддержки браузера/устройства.
