# 探秘古迹 1.2

面向中国大陆用户的移动端优先考古教育 Web 应用，基于 React、TypeScript 与 Vite。

## 本地运行

在 Windows PowerShell 中执行：

```powershell
npm.cmd install
npm.cmd run dev
```

打开 Vite 输出的本地地址（通常为 `http://localhost:5173`）。

## 学习功能

- **内容中心**：阅读中国考古专题文章，查看相关遗址、文物、术语和练习题。
- **文物图鉴**：搜索、筛选、查看文物资料、收藏条目并加入研学护照。
- **考古课堂与词典**：按顺序学习考古方法模块，查询术语和应用示例。
- **云探方**：操作三个明确标注为教学模拟的场景，逐层发现材料并记录模拟层位。
- **文物修复**：通过选择构件和目标位置完成五项教学拼合练习。
- **博古通今**：完成题目、查看逐项解析、复习错题并查看学习统计。
- **研学护照**：查看课程、阅读、发现、修复、收藏、测验和积分记录。
- **设置**：切换浅色或深色主题，恢复默认主题，或确认后清除本应用的本地学习记录。

研学进度和设置保存在当前浏览器的 `localStorage` 中，不提供跨设备同步。升级后的进度解析会保留旧版记录中仍可识别的积分、发现、印章和完成状态。

## 内容与图片说明

文章、文物和术语用于考古教育，条目尽量区分考古事实、解释和不确定性。有关学术争议或证据限制的内容会明确说明。模拟场景及修复拼片是教学设计，不代表真实遗址或真实发掘记录。

目前不展示未核实开放许可的第三方文物图片；相关位置会说明图片暂缺和授权状态。条目中的参考入口用于进一步查阅，不应替代正式考古发掘报告、馆藏目录或学术研究。

## 检查与构建

```powershell
npm.cmd run typecheck
npm.cmd test
npm.cmd run build
```

`npm.cmd run preview` 可在构建完成后本地预览生产版本。
